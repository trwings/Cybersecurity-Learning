# Cybersecurity Fundamentals — What is Cybersecurity?

## 1. Introduction

Cybersecurity is the practice of protecting computers, networks, applications, devices, systems, and data from unauthorized access, misuse, disruption, modification, destruction, or theft.

In simple words:

> **Cybersecurity means protecting digital systems and information from threats.**

Almost everything today depends on computers and networks:

* Banking
* Education
* Healthcare
* Government
* E-commerce
* Communication
* Transportation
* Cloud services
* Social media
* Businesses
* Industrial systems

Because these systems contain valuable information and perform important operations, they need to be protected.

---

## 2. What Does Cybersecurity Protect?

Cybersecurity does not protect only computers.

It protects several types of assets.

### 2.1 Hardware

Physical devices such as:

* Computers
* Laptops
* Smartphones
* Servers
* Routers
* Switches
* Firewalls
* Storage devices
* IoT devices

### 2.2 Software

Programs and applications such as:

* Operating systems
* Web applications
* Mobile applications
* Databases
* Security software
* Business applications

### 2.3 Data

Data is one of the most valuable assets.

Examples:

* Passwords
* Personal information
* Bank information
* Customer records
* Company documents
* Source code
* Medical records
* Emails
* Authentication credentials

### 2.4 Networks

Networks connect devices and allow them to communicate.

Examples:

* Home networks
* College networks
* Enterprise networks
* Wi-Fi networks
* Internet infrastructure

### 2.5 People

Humans are also part of cybersecurity.

Attackers frequently target people through:

* Phishing
* Social engineering
* Fake websites
* Fraudulent messages
* Malicious attachments

---

# 3. Why is Cybersecurity Important?

Cybersecurity is important because digital systems can be attacked.

A successful attack can result in:

* Data theft
* Financial loss
* Identity theft
* Privacy violations
* Service interruption
* Reputation damage
* Unauthorized access
* Data destruction
* Business disruption

For example:

Imagine an online banking system.

An attacker gains unauthorized access to customer accounts.

Possible consequences:

1. Customer information may be stolen.
2. Money may be transferred.
3. The bank may lose customer trust.
4. The bank may face legal and financial consequences.

Cybersecurity attempts to prevent or reduce these risks.

---

# 4. Cybersecurity vs Information Security

These terms are related but not exactly identical.

## Information Security

Information security focuses on protecting information regardless of its form.

Information may exist as:

* Digital files
* Printed documents
* Records
* Verbal information

## Cybersecurity

Cybersecurity primarily focuses on protecting digital systems, networks, devices, applications, and digital information.

Therefore:

> Information security is broader, while cybersecurity is strongly focused on digital environments.

---

# 5. Cybersecurity Goals

A cybersecurity program generally attempts to ensure that:

* Only authorized people can access resources.
* Data remains accurate.
* Services remain available.
* Systems are protected from attacks.
* Security incidents are detected.
* Incidents are responded to properly.
* Systems can recover after an incident.

These ideas lead to the **CIA Triad**, which is one of the most important concepts in cybersecurity.

---

# 6. CIA Triad

CIA stands for:

* **Confidentiality**
* **Integrity**
* **Availability**

These are the three fundamental security objectives.

We will study the CIA Triad in detail in a separate file.

---

# 7. Cybersecurity Attack Surface

The **attack surface** is the collection of possible points through which an attacker could attempt to enter, interact with, or affect a system.

Examples:

* Open network ports
* Web applications
* APIs
* User accounts
* Email systems
* Remote-access services
* Unpatched software
* Mobile applications
* Cloud services
* Physical interfaces

A larger attack surface generally provides more opportunities that need to be secured.

---

# 8. Cybersecurity Domains

Cybersecurity contains many different areas.

### 8.1 Network Security

Protecting networks and network traffic.

Examples:

* Firewalls
* Network monitoring
* Intrusion detection
* Network segmentation

### 8.2 Application Security

Protecting software and web applications.

Examples:

* Secure coding
* Vulnerability testing
* Authentication security
* Input validation

### 8.3 Endpoint Security

Protecting devices such as:

* Computers
* Laptops
* Servers
* Mobile devices

### 8.4 Cloud Security

Protecting cloud infrastructure, applications, identities, and data.

### 8.5 Identity and Access Management

Managing:

* Users
* Authentication
* Authorization
* Permissions
* Accounts

### 8.6 Security Operations

Security Operations Centers (SOCs) monitor systems and investigate suspicious activity.

Typical activities include:

* Log monitoring
* Alert investigation
* Threat detection
* Incident response

### 8.7 Digital Forensics and Incident Response

Digital forensics involves examining digital evidence.

Incident response involves handling security incidents.

### 8.8 Penetration Testing

Penetration testing is authorized security testing performed to identify weaknesses in systems.

A penetration tester attempts to discover vulnerabilities within an agreed scope.

### 8.9 Malware Analysis

Malware analysis involves examining malicious software to understand:

* How it works
* What it does
* How it spreads
* What indicators it leaves behind

---

# 9. Offensive Security

Offensive security focuses on finding and demonstrating security weaknesses from an attacker's perspective, but with authorization.

Examples:

* Penetration testing
* Vulnerability assessment
* Red teaming
* Web application security testing

Important:

> Security testing must be performed only on systems you own or have explicit permission to test.

---

# 10. Defensive Security

Defensive security focuses on protecting systems and detecting/responding to attacks.

Examples:

* Security monitoring
* Firewalls
* Endpoint protection
* SIEM
* Incident response
* Threat detection
* Log analysis

---

# 11. Red Team and Blue Team

## Red Team

The red team simulates attackers.

Their objective is to identify weaknesses and test defenses.

## Blue Team

The blue team focuses on defense.

Their activities include:

* Monitoring
* Detection
* Investigation
* Prevention
* Response

## Purple Team

Purple teaming combines offensive and defensive knowledge.

The objective is to improve security by sharing information between red and blue teams.

# 13. Important Beginner Terms

### Asset

Something valuable that needs protection.

### Threat

Something capable of causing harm.

### Vulnerability

A weakness that could potentially be exploited.

### Exploit

A method, technique, or code that takes advantage of a vulnerability.

### Risk

The possibility of a harmful outcome resulting from a threat exploiting a vulnerability.

### Attack

An attempt to compromise a system, account, network, application, or data.

### Security Control

A measure used to reduce security risk.

Examples:

* Passwords
* MFA
* Firewalls
* Encryption
* Backups
* Access controls

---

# 14. Basic Cybersecurity Example

Suppose a company has a web application.

The application contains a vulnerability.

An attacker discovers the vulnerability and uses it to access unauthorized information.

The chain can be represented as:

```text
Asset
  ↓
Vulnerability
  ↓
Threat Actor
  ↓
Exploit
  ↓
Attack
  ↓
Impact
```

Security professionals attempt to break this chain by:

* Removing vulnerabilities
* Limiting access
* Monitoring activity
* Detecting attacks
* Responding to incidents
* Recovering systems

The most important ideas from this chapter are:

1. Cybersecurity protects digital systems and information.

4. Offensive security finds weaknesses from an attacker's perspective.
